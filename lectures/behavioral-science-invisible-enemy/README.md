# 行動科学は感染対策の「見えない敵」を可視化する（約60分）

| ファイル | 内容 |
|---|---|
| `行動科学は感染対策の見えない敵を可視化する.pptx` | 講演スライド（45枚・約57分30秒＋質疑）。発表者ノートに台本と時間配分を記載 |
| `行動科学は感染対策の見えない敵を可視化する_スライドPDF版.pdf` | 配布・確認用のPDF |
| `引用文献リスト.pdf` | 引用27文献の書誌情報・DOI/PubMedリンク・講演で用いた要点・使用スライド |
| `src/` | スライドと文献リストの生成スクリプト |

- フォント：すべてBIZ UDゴシック（タイトル30pt以上、本文20pt以上）
- 構成：はじめに → 第1部 行動で決まる → 第2部 5つの見えない敵 → 第3部 見える化（診断する・見せる・返す／ナッジって何？） → 第4部 仕掛ける → ワーク・まとめ

## 改訂履歴

- 講演者編集版をもとに、医師の事例を5枚から2枚に削減（外来の時間帯と処方、同僚比較・理由記載、宣言ポスターの3枚を削除）し、初心者向けのナッジ解説4枚（定義、4つの道具、デフォルトの力、予防接種の予約済み）を追加。
- 現行のpptxは講演者が手作業で編集したファイルを含むため、`build.js` だけでは完全には再現できません。ナッジの4枚は `nudge.js` で生成し、統合しています。

## 再生成

```bash
cd src
npm install
node build.js raw.pptx && python3 post.py raw.pptx deck.pptx   # 初版（post.py で日本語フォント設定を統一）
node nudge.js nudge_raw.pptx && python3 post.py nudge_raw.pptx nudge.pptx  # 追加したナッジの4枚
python3 refs_pdf.py refs.pdf                                   # BIZ UDゴシックのTTFが必要（パスはスクリプト内）
```
