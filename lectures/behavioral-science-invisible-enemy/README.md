## 再生成

```bash
cd src
npm install
node build.js raw.pptx && python3 post.py raw.pptx deck.pptx   # post.py で日本語フォント設定を統一
python3 refs_pdf.py refs.pdf                                   # BIZ UDゴシックのTTFが必要（パスはスクリプト内）
```
