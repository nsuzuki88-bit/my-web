# VAE・CLABSI 自動判定ワークブック

`20XX年度サーベイランスワークシート_VAE・CLABSI自動判定版.xlsx`

> **注**：このリポジトリに置いてあるのは空のテンプレートから作った版だけです。
> 実データ入りのファイル（患者ID・氏名を含む）はリポジトリに置いていません。

年度サーベイランスワークシートの Allシートに入力するだけで、

- **VAE**：FiO2・PEEP から VAC を自動判定し、臨床所見を入れた患者は IVAC・PVAP まで判定します
- **CLABSI**：「C有」と入力した患者を自動で集め、血液培養陽性の患者を1行入力すると CLABSI かどうかを判定します
- **集計**：人工呼吸器・中心ラインの **使用比** と VAE・CLABSI の **発生率（/1,000器具日）** を月別に自動集計し、グラフにします

- **すべて数式**で実現しています。マクロ（VBA）は使っていないため、マクロが禁止されたPCでもそのまま動きます。
- **ファイルは1つ**です。元の `20XX年度サーベイランスワークシート` にシートを追加したものなので、
  ブック間リンク切れの心配がありません。既存の Allシート・上半期/下半期/年間集計シート・グラフも残しています。
- **Excelで確実に計算される形**で保存しています。範囲全体をまとめて計算する数式は配列数式（`{=…}`）、
  名前付き範囲は `VAE_D0` のようにセル番地と紛れない名前にしています（下の「Excelでの注意」参照）。
  また、全数式セルとグラフに計算結果を保存済みなので、保護ビューやファイルのプレビューでも判定結果とグラフが表示されます。

## シートの一覧

| シート | 役割 |
| --- | --- |
| `使い方` | 操作手順と判定ロジックの要約 |
| `All` | 従来どおり V有無／FiO2／PEEP／C有無／部屋 を入力（入力方法は変更なし） |
| `VAE対象一覧` | **AllのデータからVAC判定（DOE）を直接実施**。VAC患者の一覧（DOEの早い順）・全ブロックのスキャン |
| `臨床所見` | **VACと判定された患者だけ**のスロット。項目ごとに色分けし、DOE±2日の列を黄色で表示 |
| `VAE-01`〜`VAE-10` | **臨床所見に入力した患者だけ**に割り当てられる個別判定シート（10枚）。IVAC・PVAPまで判定 |
| `VAE集計` | 人工呼吸器使用比と VAC／IVAC／PVAP の件数・発生率を月別に自動集計（グラフ2つ） |
| `CLABSI判定` | **「C有」の患者を自動で収集**（セクションB）。血液培養陽性の患者を入力すると判定（セクションA） |
| `CLABSI集計` | 中心ライン使用比と CLABSI の件数・発生率（LCBI＋CSEP／LCBIのみ）を月別に自動集計（グラフ2つ） |
| 上半期／下半期／年間集計 | 既存のシート。発生件数（これまで手入力）が自動で入るようにつないだ |

### 既存の集計シートに加えた変更

| シート | 変更 |
| --- | --- |
| `年間集計(VAE)` | VAC・IVAC・PVAP の件数を `VAE集計` から自動で入れる。年度計の使用比を「月ごとの比の平均」から「年間合計÷年間合計」に修正 |
| `年間集計(CLABSI)` | 件数を `CLABSI集計`（LCBI＋CSEP）から自動で入れる。題名の誤り（「VAEサーベイランス」）を修正。年度計の使用比を合計から計算。**参照が `#REF!` で何も表示されていなかったグラフ**を発生密度率（8行目）に修正し、残っていた縦軸の上限20を外した |
| `上半期 (CLABSI)` | 件数（4〜6月が0の固定値、7〜9月が空欄だった）を `年間集計(CLABSI)` から参照 |

上半期／下半期の各シートとそのグラフは、年間集計の件数から自動で更新されます。

## 使い方

```
Allシート                         全患者の V有無／FiO2／PEEP／C有無 を毎日入力（従来どおり）
 │
 ├─ VAE ── VAE対象一覧（自動） ── VACの患者だけ ── 臨床所見（体温・WBC・抗菌薬・PVAP）
 │                                                        └─ 入力した患者だけ ── VAE-01〜10（IVAC・PVAP）
 │          └────────────────────────────────── VAE集計（使用比・発生率・グラフ）
 │
 └─ CLABSI ─ CLABSI判定 セクションB（「C有」の患者を自動で収集）
             CLABSI判定 セクションA（血液培養陽性の患者だけ1行入力 → 判定）
             └────────────────────────────────── CLABSI集計（使用比・発生率・グラフ）
```

入力が必要な黄色のセルは次のとおりです。

| シート | 入力するもの |
| --- | --- |
| `All` | V有無／FiO2／PEEP／C有無／部屋、A列に患者ID・氏名 |
| `臨床所見` | VACの患者の DOE±2日（黄色の列）の 体温・WBC・新規抗菌薬・PVAP基準 |
| `CLABSI判定` セクションA | 患者ID・血液培養採取日・検出菌名・菌の分類・症状の初日・2次性BSI・CSEP |
| `VAE対象一覧` セクションB | 年齢・臓器提供同意日・備考（必要な患者だけ） |
| `VAE-01`〜 | エピソードが2回ある患者のみ C9 を 2 に |

### 臨床所見シートの色分け

| 色 | 意味 |
| --- | --- |
| 橙・青・緑・紫（B列と入力欄） | 項目のまとまり：体温・WBC・抗菌薬・PVAP基準 |
| **黄色の列** | DOE±2日（VAEウィンドウ）＝ **ここに入力** |
| **濃い橙の列** | DOE当日（DOE①・DOE②） |
| 灰色のスロット | 未割当（入力不要） |
| 太線／縦の太線 | スロットの境目／月の変わり目 |

A列の **「▶DOE前後へ」** をクリックすると、365日分を横スクロールせずにDOEの列へ移動できます。
セルを選ぶと入力のヒントが表示され、体温（34〜42℃の外）・WBC（1,000〜300,000/μLの外）は
単位の取り違え（例：WBCを 12.0 と入力）を警告します。

### スロットの並び（臨床所見・VAE対象一覧セクションA）

VAC の患者は **DOE① の早い順**（同じ日はブロック番号順）に並びます。Allは日付順に入力していくので、
新しくVACになった患者は必ず末尾に付き、**臨床所見を入力済みのスロットの並びは変わりません**。
（以前はブロック番号順だったため、前のブロックの患者が後からVACになると並びがずれるおそれがありました。）
念のため、入力があるのに DOE±2日 に値がないスロットには A列に **「⚠割当確認」** が出ます。

### CLABSI判定シート

- **セクションB**：Allシートで一度でも「C有」と入力された患者を、**CL初日の早い順**に自動で並べます
  （患者ID・氏名・ブロック・部屋・ICU入室日・CL初日・CL最終日・CL日数・CLABSIの対象になる最初の日（CL3日目）・判定）。
- **セクションA**：血液培養が陽性になった患者（またはCSEPを疑う患者）だけを1行ずつ入力します。
  患者IDからAllのブロックを探し（同じIDが複数あればDOEが在室期間に入るブロック）、
  DOE・ICU在室日・中心ライン留置日数・RIT を Allシートから自動で求めて判定します。
- 判定の入力を一覧の行に持たせていないのは、一覧が数式で並ぶため、Allを修正すると並びが変わって
  入力と患者がずれるおそれがあるからです。セクションAは患者IDで患者を指定するので、並びに左右されません。

### Allシートの赤色（FiO2・PEEP の行）

| 色 | 意味 |
| --- | --- |
| **濃い赤（白文字）** | **DOE（イベント発生日）**。イベント期間14日による重複排除まで適用済み |
| 薄い赤 | VACの基準に合致したが、上のDOEには当たらない日（直前のDOEから14日以内 など） |

> 元のAllシートに入っていた条件付き書式（空テンプレート 3,920ルール、2026年度ファイル 23,563ルール）は、
> `#REF!` エラーや参照位置のずれ（入力したセルと無関係の数行下のセルが赤くなる）があったため削除し、上の2ルールに置き換えています。

### 足りなくなったら

判定シートは10枚です。11人目以降は `VAE対象一覧` の「シートへ」の列に「シート不足」と出ます。
最後の `VAE-10` のタブを右クリック →「移動またはコピー」→「コピーを作成する」で複製し、
`C4` と `B78` の数式内の `10` を `11` に書き換えてください（ビルド時に `build.py` の第3引数でも指定できます）。
`VAE対象一覧` セクションBと `CLABSI判定` セクションBは Allシートの先頭1,200ブロックを見ています。

## 判定ロジック

### VAE（NHSN／JHAIS）

| 項目 | 実装 |
| --- | --- |
| 日最小値 | その暦日内で1時間を超えて維持された最低の PEEP／FiO2 |
| PEEP 0〜5 cmH2O | 同等とみなし 5 として自動補正 |
| ベースライン期間 | 悪化初日の直前2日。2暦日以上の安定または低下 |
| VAC | ベースライン初日比で FiO2 +20ポイント以上 **または** PEEP +3cmH2O以上 が2暦日以上持続。最早DOEはMV3日目 |
| VAEウィンドウ | DOE±2日（5日間）。ただしMV3日目以降 |
| IVAC | VAC成立＋ウィンドウ内に 体温>38℃ or <36℃、あるいは WBC≥12,000 or ≤4,000/mm³ **かつ** 新規抗菌薬開始（4QAD以上） |
| PVAP | IVAC成立＋ウィンドウ内に PVAP基準1〜3 のいずれか |
| イベント期間 | DOEを1日目とする14日間は新規VAEを判定しない（次の最早DOEは15日目） |
| MV日 | V有無が「V有」の日。空欄のときはFiO2／PEEPに入力があればMV日。「V無」「V有（NIV）」は除外 |

### CLABSI（JHAIS Ver.2.5）

| 項目 | 実装 |
| --- | --- |
| 中心ライン日 | C有無が「C有」の日。1暦日以上「C有」が途切れたら、次の「C有」から数え直す（JHAISの患者D） |
| LCBI-1 | 認定病原体（皮膚常在菌以外）。DOE＝血液培養採取日 |
| LCBI-2 | 同じ皮膚常在菌が2セット以上＋発熱(>38.0℃)・悪寒戦慄・低血圧が IWP（採取日±3日）内。DOE＝採取日と症状の初日の早い方 |
| CSEP | 血液培養陰性・未実施＋医師が敗血症として治療開始（JHAIS独自の基準）。DOE＝症状の初日 |
| CLABSI | 上のいずれか＋DOEまたは前日に **2暦日を超えて（CL3日目以降）留置された中心ライン**。抜去日・抜去翌日のDOEも含む |
| ICUへの帰属 | ICU入室2日以内のDOEは POA または転棟元に帰属（対象外）。ICU退室翌日のDOEはICUに帰属。退室翌々日以降はICU外 |
| RIT | 一次BSIのDOEから14日間は、同じ患者の血流感染を新規にしない（菌は前回に追加）。2次性BSIはRITを作らない |
| 対象外 | 皮膚常在菌1セットのみ（汚染菌）、他部位感染の2次性BSI、LCBI除外病原体 |

LCBI-3（1歳以下）は、JHAISが1歳以下を分母から除くため実装していません。
NHSN独自の MBI-LCBI・CLABSI除外条件（ECMO・VAD等）が必要な場合は、`CLABSI_VAE_デバイスサーベイランス_ワークシート.xlsx`
の ④CLABSI判定 で個別に判定してください。

### 使用比と発生率（JHAIS Ver.2.5 p.8・p.12–14）

| 指標 | 計算 |
| --- | --- |
| 発生率 | 件数 ÷ 延べ医療器具使用日数 × 1,000（VAE：/1,000人工呼吸器日、CLABSI：/1,000中心ライン日） |
| 使用比 | 延べ医療器具使用日数 ÷ 延べ入室患者日数 |
| 分母 | Allシート上部の「人工呼吸器使用患者数」（V有）・「CV挿入患者数」（C有）・「ICU入室患者数」（C有＋C無）の日ごとの値を月ごとに合計 |
| 年度計 | 月ごとの率の平均ではなく、年間の合計から計算（pooled） |
| VAEの件数 | 1件を最上位の段階（VAC→IVAC→PVAP）で1回だけ数える。IVAC-plus（IVAC＋PVAP）も表示 |
| CLABSIの件数 | JHAISにならい「LCBI＋CSEP」と「LCBIのみ」の両方を表示 |

グラフの色は、VAEの段階（VAC→IVAC→PVAP）を同じ青の濃淡、CLABSIの基準（LCBI・CSEP）を青と橙にしています
（色覚の多様性に配慮した組合せを検証スクリプトで確認済み）。まだデータのない月はグラフに描きません。

根拠と出典は次の2つのPDFにまとめています。

- `引用文献リスト_VAE自動判定ワークシート.pdf` … VAE判定ロジック
- `引用文献リスト_CLABSI判定・使用比集計.pdf` … CLABSI判定・使用比と発生率の計算・参考値・フィードバックの効果

> **自動判定は判定の補助です。** 最終判定は原典プロトコール（NHSN PSC Manual／JHAIS マニュアル）と
> 診療記録に基づき、感染管理担当者が行ってください。

## 検証

4通りの方法で検証しています（最新の実行で **全項目一致**、Excel互換の点検で **問題0件**）。

1. **独立実装との照合** — 同じアルゴリズムを Python で別に実装し（VAE：`tools/ref_vae.py`、
   CLABSI：`tools/ref_clabsi.py`）、表計算の結果と突き合わせます。
2. **教科書例との照合** — NHSN／JHAIS マニュアルの例を投入し、LibreOffice で全再計算して、
   規則から手で導いた期待値と照合します。
3. **保存した計算結果の照合** — 完成版のファイルに保存した値そのもの（Excelが開く前の値）を独立実装と照合します。
4. **Excel互換の点検** — `tools/audit_xl.py` で、配列計算が配列数式になっているか・名前付き範囲が
   セル番地と衝突しないか・Excel 2010 にない関数を使っていないか・未定義の名前がないかを全数式について点検します。

（`""-2` の `#VALUE!` で条件付き書式の式全体が止まる）を2か所で見つけて修正しました。どちらも Excel でも同じ動きです。

## Excelでの注意

- **配列数式を編集しない**：`VAE対象一覧` の非表示列 P・Q、判定シート78行目、`CLABSI判定` の非表示列（V〜AE、AJ〜AT）の
  数式は配列数式（数式バーで `{=…}` と表示）です。編集して Enter だけで確定すると、古いExcelでは配列数式でなくなり判定が止まります。
- 以前の版では、SUMPRODUCT の中の IF が配列数式になっていなかったため、Excelでは一覧・臨床所見・判定シートが
  空欄になっていました。また名前付き範囲 `rD1`・`rD2` がセル番地と同じ綴りでした。どちらも修正済みで、
  `audit_xl.py` で再発を点検しています。
