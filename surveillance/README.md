# VAE 個別判定シート 自動作成ワークブック

`20XX年度サーベイランスワークシート_VAE個別判定自動作成版.xlsx`

> **注**：このリポジトリに置いてあるのは空のテンプレートから作った版だけです。
> 実データ入りのファイル（患者ID・氏名を含む）はリポジトリに置いていません。

## Allシートの構造は自動判定します

年度ファイルによって Allシートの構造が違うため、`tools/build.py` は実ファイルから
日付行・ブロック先頭行・ブロック数・最終行を読み取ってから各シートを生成します。

| 項目 | 空テンプレート | 2026年度ファイル |
| --- | --- | --- |
| 日付行 | 5行目 | 6行目（1行目にもマクロ用の日付） |
| ブロック先頭行 | 6行目 | 7行目 |
| 患者ID・氏名 | A列のラベルの1つ下（ID＝ブロック先頭+1行、氏名＝+3行） | 同左 |
| FiO2 | ％でも小数でも可（`IF(x>1,x/100,x)` で正規化） | 小数（0.4） |
| ブロック数 | 399 | 2361 |

`.xlsm` を渡した場合はマクロを保持したまま `.xlsm` で出力します。

Allシートに **FiO2 と PEEP を入力すると、人工呼吸器装着患者が自動で検出され、
個別判定シート（⑤VAE判定と同じ様式）が自動で作成・更新される** ようにしたものです。

- **すべて数式**で実現しています。マクロ（VBA）は使っていないため、マクロが禁止されたPCでもそのまま動きます。
- **ファイルは1つ**です。元の `20XX年度サーベイランスワークシート` にシートを追加したものなので、
  ブック間リンク切れの心配がありません。既存のAllシート・上半期/下半期/年間集計シート・
  16個のグラフはそのまま残しています。

## 追加したシート

| シート | 役割 |
| --- | --- |
| `使い方` | 操作手順と判定ロジックの要約 |
| `VAE対象一覧` | **AllのデータからVAC判定（DOE）を直接実施**。VAC患者の一覧・全ブロックのスキャン・月別集計 |
| `臨床所見` | **VACと判定された患者だけ**のスロット。体温・WBC・新規抗菌薬・PVAP基準を入力 |
| `VAE-01`〜 | **臨床所見に入力した患者だけ**に割り当てられる個別判定シート。IVAC・PVAPまで判定 |

既存の `All` と集計シート6枚は**変更していません**（B列ラベルの誤記修復を除く）。

## 使い方 ― 4段階でしぼり込みます

```
Allシート          全患者の FiO2/PEEP を毎日入力（従来どおり）
   ↓ 自動
VAE対象一覧 セクションB   全ブロックのVAC判定（DOE）を自動実施
   ↓ VACと判定された患者だけ
VAE対象一覧 セクションA ＝ 臨床所見のスロット
   ↓ 体温・WBC・抗菌薬・PVAP基準を入力した患者だけ
VAE-01〜           個別判定シートが自動作成され、IVAC・PVAP まで判定
```

1. **`All`シート** — これまで通り V有無 / FiO2 / PEEP / C有無 / 部屋 を入力。
2. **`VAE対象一覧` セクションB** — 全ブロックの MV日数・DOE・VAC判定が自動で出ます。
   MV日数が4日以上のブロックが判定対象です（JHAIS：VAEの対象は人工呼吸を暦日で4日以上）。
3. **`VAE対象一覧` セクションA** — VACと判定された患者だけが上から順に並びます。
   この番号が `臨床所見` のスロット番号と一致します。
4. **`臨床所見`** — 該当スロットに、DOE前後の 体温・WBC・新規抗菌薬・PVAP基準 を入力。
5. **`VAE-01`〜** — 4で入力した患者だけに自動で割り当てられ、IVAC・PVAP まで判定されます。
   結果はセクションAの「判定①」に反映されます。

入力が必要な黄色のセルは、`All`・`臨床所見`・一覧シート セクションBの年齢／臓器提供同意日／備考、
および各判定シートの **エピソード番号（C9）** だけです。

### スロットの割当について

臨床所見のスロットは VAC患者を**ブロック番号順**に並べて自動割当します。
すでに入力済みの患者より前のブロックが新たにVACになると割当がずれる可能性があるため、
各スロットのA列に **患者ID・氏名・DOE** を表示しています。
また、入力があるのに DOE±2日 に値がないスロットには **「⚠割当確認」** が出ます。

### Allシートの赤色（FiO2・PEEP の行）

FiO2 と PEEP が JHAIS の酸素化悪化基準に合致すると、その日のセルが赤くなります。

| 色 | 意味 |
| --- | --- |
| **濃い赤（白文字）** | **DOE（イベント発生日）**。個別判定シートが報告する日で、イベント期間14日による重複排除まで適用済み |
| 薄い赤 | JHAISの酸素化悪化基準（VAC）に合致したが、上のDOEには当たらない日。＝直前のDOEから14日以内で新規報告の対象外か、まだ判定シートが割り当てられていない患者。`VAE対象一覧` で判定を確認してください |

凡例は `All` シートの **A5セルのコメント**（赤い三角にマウスを乗せる）にも入れてあります。

> **元のAllシートに入っていた条件付き書式 3,920 ルールは削除しました。**
> 同じVAC判定を意図したものでしたが、
> ①半数（1,960ルール）に `#REF!` エラーが残っている、
> ②FiO2 を分数として比較（`>=0.2`）しているがシートには％（40・60等）で入力する、
> ③相対参照が4列左・7行上にずれており、**入力したセルとは無関係の数行下のセルが赤くなる**、
> という状態でした。上の2ルールに置き換えています。

### MV日（人工呼吸器装着日）の判定ルール

- **MV日とみなす日** … `All` の V有無行が「V有」の日。
  V有無が**空欄**のときだけ、FiO2／PEEP に入力があればMV日とみなします
- **除外する日** … 「V無」の日と「V有（NIV）」の日（非侵襲的換気はVAEの対象外）
- **エピソード** … 1暦日以上完全に離脱したあとの再装着は別エピソード。
  判定シートの `C9` を 2 に変えると2件目を判定します（最大6件）
- **VAC判定の対象** … MV日数が **4日以上**のブロック
  （JHAIS：VAEの対象は人工呼吸を暦日で4日以上）
- **FiO2の単位** … 小数（0.4）でも％（40）でも同じ判定になります

### 足りなくなったら

判定シートの枚数・臨床所見のスロット数・スキャン範囲は、ビルド時のVAC患者数から
自動で決まります。手で増やす場合は、最後の `VAE-nn` のタブを右クリック →
「移動またはコピー」→「コピーを作成する」で複製し、`C4` と `B78` の数式内の番号を
1つ増やしてください。特定の患者に固定したいときは `C4` に
一覧シート セクションBのブロック番号を直接入力します。

## 判定ロジック（NHSN / JHAIS 準拠）

| 項目 | 実装 |
| --- | --- |
| 日最小値 | その暦日内で1時間を超えて維持された最低の PEEP／FiO2 |
| PEEP 0〜5 cmH2O | 同等とみなし 5 として自動補正 |
| ベースライン期間 | 悪化初日の直前2日。2暦日以上の安定または低下 |
| VAC | ベースライン初日比で FiO2 +20ポイント以上 **または** PEEP +3cmH2O以上 が2暦日以上持続。最早DOEはMV3日目 |
| VAEウィンドウ | DOE±2日（5日間）。ただしMV3日目以降 |
| IVAC | VAC成立＋ウィンドウ内に 体温>38℃ or <36℃、あるいは WBC≥12,000 or ≤4,000/mm³ **かつ** 新規抗菌薬開始（4QAD以上） |
| PVAP | IVAC成立＋ウィンドウ内に PVAP基準1〜3 のいずれか |
| イベント期間 | DOEを1日目とする14日間は新規VAEを判定しない（次の最早DOEは15日目） |

根拠と出典は `引用文献リスト_VAE自動判定ワークシート.pdf` にまとめています。

> **自動判定は判定の補助です。** 最終判定は原典プロトコール（NHSN PSC Manual Chapter 10／
> JHAIS 医療器具関連感染サーベイランス マニュアル）と診療記録に基づき、
> 感染管理担当者が行ってください。電子的実装のわずかな違いでVAE発生率が変動することが
> 報告されています（引用文献 [2]）。

## 検証

2通りの方法で検証しています（**合計 15,120項目すべて一致**）。

1. **独立実装との照合** — 同じ NHSN/JHAIS アルゴリズムを Python で別に実装し
   （`tools/ref_vae.py`）、表計算の結果と全ブロック分を突き合わせます。
   表計算の数式と別実装を突き合わせることで、実装の取り違えを相互に検出できます。
2. **教科書例との照合** — NHSN／JHAIS マニュアルの例をワークシートに投入し、
   LibreOffice で全再計算して期待値と照合します。

| 検証項目 | 内容 |
| --- | --- |
| PEEP経路のVAC | PEEP 5,5,5,5,8,8 → DOE = MV5日目 |
| PEEP 0〜5の同等扱い | PEEP 0,0,0,3,3,3 → 補正後は全日5のため VAC にならない |
| FiO2経路のVAC | FiO2 40,40,40,60,60,60 → DOE = MV4日目 |
| 最早DOE | FiO2 40,40,70,70 → DOE = MV3日目 |
| イベント期間14日 | MV3日目にDOE → MV7日目の悪化は検出せず、MV17日目は新規VAEとして検出 |
| エピソード分割 | 5日装着→2日離脱→8日装着 → 2エピソード |
| NIV除外 | 「V有（NIV）」のみの患者は MV日数 0・VAC判定なし |
| V無の優先 | 「V無」の日は FiO2/PEEP が入力されていてもMV日にしない |
| 二進小数の境界 | FiO2 ちょうど+20ポイント（`0.4→0.6` は計算上 `0.19999999999999996`）と PEEP ちょうど+3cmH2O を、％入力・小数入力の両方で検出 |
| しぼり込みの連鎖 | 臨床所見に入力 → 個別判定シートが自動割当 → IVAC・PVAPへ格上げ → 一覧と月次集計に反映 |
| 入力追従 | VACが消える／新たに増える／患者を追加する と、一覧・臨床所見・判定シートの割当がすべて追従 |
| 体温・WBCだけではIVACにならない | 体温38.6℃のみ／WBC 15,200のみ → 異常フラグは立つが新規抗菌薬がないため VAC のまま |
| 体温・WBCの境界値 | 38.0℃ちょうど→異常でない（>38℃）／38.1℃→異常／35.9℃→異常（<36℃）／WBC 12,000ちょうど→異常（≥12,000）／WBC 4,000ちょうど→異常（≤4,000） |
| VAEウィンドウ | DOE+5日に体温・WBC・抗菌薬を入れても IVAC にならない（DOE±2日の外） |
| 割当ずれの検知 | DOEから離れた日に入力したスロットに「⚠割当確認」が出る |
| Allシートの赤色 | 条件付き書式の式を同じ行・列で評価し、濃い赤／薄い赤になるセルを照合 |

再検証する場合：

```bash
cd tools
python3 build.py <元の年度ワークシート>.xlsx out.xlsx   # ビルド（構造は自動判定）
python3 make_tests.py                                   # 教科書例を投入
python3 recalc.py test.xlsx test_calc.xlsx              # LibreOfficeで全再計算
python3 strip_charts.py test_calc.xlsx test_plain.xlsx
python3 check.py test_plain.xlsx test.xlsx              # 独立実装＋期待値と照合
python3 test_live.py mutate test.xlsx test2.xlsx        # 入力追従の検証
python3 test_cf.py make test.xlsx cft.xlsx              # Allシートの条件付き書式の検証
python3 test_clin.py make out.xlsx clin_t.xlsx plan.json  # 体温・WBCの入力挙動と境界値
python3 ref_vae.py <年度ワークシート>.xlsx              # 独立実装だけを単独で実行
```

`build.py` の引数：`build.py <入力> <出力> [判定シート枚数] [スキャン範囲] [臨床所見スロット数]`

必要パッケージ：`openpyxl`、`reportlab`、`libreoffice-calc`、`python3-uno`

## 補足

- 来年度の空ワークシートにも同じ機能を入れられます。
  `python3 tools/build.py 20YY年度サーベイランスワークシート.xlsx 出力.xlsx` を実行してください。
  Allシートの構造（5行/ブロック、C列=年度初日、NC列=年度末日）が同じであれば、そのまま使えます。
- 既存の `CLABSI_VAE_デバイスサーベイランス_ワークシート.xlsx` は変更していません。
  CLABSI判定（④）と手入力用の⑤VAE判定テンプレートは引き続きそちらをお使いください。
- なお、そちらの `⑤VAE判定` シートのVAEウィンドウ着色（条件付き書式）は、
  DOEの**前2日しか**橙色にならない式になっています。本ファイルの判定シートでは
  DOE±2日が正しく着色されるよう修正しています（着色のみの問題で、判定結果には影響しません）。
