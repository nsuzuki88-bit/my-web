# HHSAF 手指衛生自己評価アプリ

WHO「手指衛生自己評価フレームワーク 2010（Hand Hygiene Self-Assessment Framework, HHSAF）」のチェックリストをWebアプリにしたものです。

- `index.html` … アプリ本体（1ファイル完結。外部ライブラリなし、ブラウザで開くだけで動きます）
- `references-hhsaf.pdf` … 引用文献リスト（書誌・研究デザイン・主な知見・アプリでの用途、改善アクション別の根拠表）
- `tools/build-references-pdf.mjs` … 引用文献リストPDFを `index.html` のデータから再生成するスクリプト

## できること

| 機能 | 内容 |
| --- | --- |
| 評価票 | 5構成要素・51設問（27指標）＋リーダーシップ基準20項目。回答するとその場で採点 |
| 総合レベル | 0〜125 不十分／126〜250 基本／251〜375 中級／376〜500 上級（WHOの解釈文つき） |
| レーダーチャート | 構成要素別の得点（各100点）。「この評価を記録」した過去の評価と重ねて比較 |
| 推奨事項 | 総合レベル別の次の目標と、構成要素ごとの得点帯（0〜25／26〜50／51〜75／76〜100）に応じたガイドライン上の推奨。満点に届いていない設問も表示 |
| 優先順位 | 未達の設問を39の改善アクションにまとめ、**効果×実施の容易さ**の高い順に表示。優先度マトリクス、HHSAF得点の伸び、根拠文献つき |
| 保存・出力 | ブラウザ内への自動保存、評価の記録と比較、JSON保存・読み込み、結果のテキストコピー、印刷 |

回答はブラウザ内（localStorage）にのみ保存され、外部には送信されません。別のPCで使う場合や確実に残す場合は「JSONで保存」を使ってください。

## 採点のルール（HHSAF 2010）

- 設問1.7（インフラ改善計画）は、1.1〜1.6の合計が100点未満のときだけ得点します。
- 3.4a・3.4b（直接観察）は、観察者が訓練・検証を受け「手指衛生の5つのタイミング」（または同等）の方法で観察しているときだけ得点します。アプリでは「回答条件」の設問で判定します。
- 未回答の設問は0点として計算します。
- リーダーシップレベルは、上級（376点以上）かつ、20項目中12項目以上「はい」、かつ各構成要素で1項目以上「はい」のときに判定します。日本語訳版の判定文は「または」と読める表記ですが、WHO英語版原典と国際調査（de Kraker 2022）の運用に合わせています。

## 優先順位のつけ方

各改善アクションに、引用文献にもとづいて次の2つを1〜5で割り当て、その積（1〜25）を優先度としています。

- **期待される効果**：5＝RCT・メタ解析・大規模研究で遵守率または感染の改善が一貫して示された中核の対策 … 1＝効果のエビデンスが乏しい
- **実施の容易さ**：5＝感染対策部門の裁量で1か月以内・費用ほぼなし … 1＝設備投資や工事を伴う長期計画

効果4以上かつ容易さ4以上を「最優先」、効果4以上で容易さ3以下を「計画的に推進」、効果3以下で容易さ4以上を「手早く補強」、それ以外を「条件が整えば」に区分します。ABHRの設置（1.1）と研修の頻度（2.1a）は、現在の回答によって容易さが変わります。各アクションの評価と根拠は `references-hhsaf.pdf` の付録にまとめています。

主な根拠：WHO手指衛生ガイドライン（2009）、HHSAF（2010）、Pittet D, Lancet 2000、Allegranzi B, Lancet Infect Dis 2013、Luangasanatip N, BMJ 2015、Gould DJ, Cochrane 2017、Ivers N, Cochrane 2012、Stewardson AJ, Lancet Infect Dis 2016、Grayson ML, Lancet Infect Dis 2018、Zingg W, Lancet Infect Dis 2015、de Kraker MEA, Lancet Infect Dis 2022、SHEA/IDSA/APIC 2022 など全30件。

## 引用文献PDFの再生成

`index.html` の文献データ（`REFS`）や改善アクション（`ACTIONS`）を変更したら、次のコマンドでPDFを作り直します（Chromiumが必要です）。

```
node hhsaf/tools/build-references-pdf.mjs
```

Chromiumの場所が異なる場合は `CHROME=/path/to/chrome node hhsaf/tools/build-references-pdf.mjs` のように指定します。

## 注意

本アプリはWHO HHSAF 2010（日本語訳：市川高夫）の設問と配点にもとづいて独自に作成した自己評価支援ツールで、WHOが作成・承認したものではありません。設問文は原典の趣旨に沿って平易に言い換えています。効果・容易さの評価は作成者の判断であり、最終的な行動計画は感染対策委員会などで施設の状況に合わせて決定してください。
